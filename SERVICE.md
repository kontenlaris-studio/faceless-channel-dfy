## Intake questions (send by email after payment/order confirmation)

1. Channel/brand name (and links to existing channels, if any)
2. Niche — pick or propose: facts/history, tech tips, quotes & stories,
   product facts, other (must fit the text-driven format)
3. Language: Indonesian or English
4. Target platforms: YouTube Shorts / TikTok / Reels (which combination)
5. Format preference: TTS narration or captioned-silent
6. Tone references: 2–3 channels whose style you like (for direction only —
   we never copy their content)
7. Upload access model: A (we deliver files, you upload) or B (you grant
   upload access via the platform's permission features — never passwords)
8. Anything off-limits: topics, claims, words, competitors to avoid
9. Posting days/times preference (or accept our default schedule)
10. Where should deliveries and reports be sent? (email / Drive folder)

## Production cadence

| When | What |
|---|---|
| Day 0 | Intake complete; niche locked with client |
| Week 1 | 4 pilot videos produced and sent for review |
| Client review | 48h window; format/tone fixes applied once |
| After approval | Steady cadence: 3 videos/week (12/month) |
| Weekly | Delivery batch: video files + titles/descriptions/hashtags + posting schedule |
| Month end | Performance report + next-month plan (see template below) |

Pipeline per video: Trend Scout topic pick → Story-to-Shorts script →
Talking-Head render (1080×1920, frame animation + captions/TTS) →
ClipSmith assembly → QC → delivery/upload per access model.

## QC checklist (per video, before delivery)

- [ ] 1080×1920, vertical, plays cleanly start to finish (no frozen frames)
- [ ] Captions burned in, spelled correctly, readable size, in channel language
- [ ] TTS (if used) matches the script text exactly; no cut-off words
- [ ] Script is original/generated — no copied text, no third-party footage
- [ ] No unverifiable claims stated as fact; facts niche double-checked
- [ ] Title, description and hashtags written and matched to the right video
- [ ] File named per convention: `YYYY-MM-DD_<slug>.mp4`
- [ ] Added to the month's delivery log and posting schedule

## Access models

- **Model A — client uploads.** We deliver finished MP4s + copy blocks.
  Client uploads to their own schedule (we provide the plan). Zero access
  needed; default for new clients.
- **Model B — granted upload access.** Client adds our account through the
  platform's own permission system (e.g. YouTube Studio permissions /
  TikTok & Meta equivalents) with upload-only scope where possible.
  **Never accept or store a client's password.** Revocation is the client's
  right at any time and ends uploads immediately.

## Boundaries (non-negotiable)

- **No guarantees** of views, subscribers, revenue, or monetization
  eligibility — in copy, in sales calls, anywhere. We sell consistent
  production, not outcomes.
- **Original content only.** No re-uploaded footage, no copied scripts, no
  copyrighted material. Pipeline-generated scripts and visuals only.
- **Client approves niche and pilots** before steady production starts.
  No publishing in a format the client has not seen.
- **Client owns the channel and all delivered videos** — during and after
  the engagement.
- **No fake engagement**: no bought views/likes/subscribers, no engagement
  pods, no spam comments — ever, even if a client asks.
- **No password handling** (see Access models). Access only via platform
  permission features, or Model A.
- Honest format limits, always stated: frame animation + captions/TTS,
  **no lip-sync**, no human presenter.
- Facts come from research per video; never invent statistics, quotes, or
  attributions for a client's niche.
